About QuickNotes

QuickNotes is a simple note-taking app for jotting down ideas, reminders and to-dos the moment they come to mind. It keeps your notes organised and easy to find, so nothing important gets lost.

How to use QuickNotes

  1. Open QuickNotes and click the "New note" button.
  2. Type a title and write your note.
  3. Save the note so it is stored in your list.
  4. Use the search box to find a note later.

Features

  • Create notes in one click
  • Fast search across all notes
  • Simple, distraction-free layout
  • Keyboard shortcuts for common actions

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + F Search your notes
